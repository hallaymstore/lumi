# Lumi v1.5 — Public Discovery + SEO + Admin Control

- Bottom navbar simplified to Feed / Qidiruv / Create / Chat / Faollik. Profile remains in the top-right avatar.
- Guest browsing for home, feed, explore, public profiles, post permalinks and comment/like lists.
- Auth-required bottom sheet for like, comment writing, follow, save, chat and create actions.
- Every post has `/p/:id` permanent public URL.
- Open Graph, Twitter card, canonical URL and JSON-LD metadata for rich external previews.
- Telegram, WhatsApp, X, native share and copy-link actions.
- Dynamic `robots.txt` and `sitemap.xml`.
- Unique post views include anonymous visitors using a privacy-preserving browser id hash.
- Search/explore is public. Profile grids and explore tiles open exact post links.
- Expanded admin dashboard: system health, users, posts, views, likes, comments, stories, chats, reports, verification, creator role, suspension, announcement and audit log.
- PWA cache bumped to v1.5.
